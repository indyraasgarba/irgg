Publish with GitHub Pages:
1. Create a free GitHub account and a public repository.
2. Upload all three files to the repository's top/root folder.
3. In the repository, open Settings > Pages and enable publishing from the main branch/root folder.
4. In Settings > Pages > Custom domain, enter your domain and save.
5. Configure DNS at your domain registrar as GitHub instructs. Do not delete existing MX/TXT records used for email.
6. After DNS is configured and HTTPS is available, test the website and PDF links.
